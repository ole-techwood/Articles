# 05: Responsive accessible finish

**What to build:** Finish the Menu Browser as a polished rustic Mamma Pizza! experience. Show a centered phone-like Story Frame on desktop and a full-viewport Story Frame on mobile. Apply the 60-30-10 Palette, prevent content overlap, and respect reduced-motion and accessibility requirements across the complete interaction.

**Blocked by:** 02: Category Navigation; 03: Manual Story browsing; 04: Timed Story playback.

**Status:** ready-for-agent

- [ ] Desktop renders a centered, visually bounded portrait Story Frame.
- [ ] Mobile renders a full-viewport Story Frame.
- [ ] Story Frame dimensions remain stable while Stories change.
- [ ] Titles, descriptions, ingredients, prices, Nutrition Facts, and controls remain readable without overlap at desktop and mobile sizes.
- [ ] Warm paper dominates the Palette, deep olive provides structure, tomato red provides accents, and charcoal provides readable text.
- [ ] Palette proportions follow the 60-30-10 rule with sufficient contrast.
- [ ] Reduced-motion preference removes animated transitions while preserving playback and manual navigation.
- [ ] Semantic controls expose accessible names and playback state.
- [ ] Focus indicators remain visible and touch targets remain usable.
- [ ] User-facing tests verify responsive layout assumptions, reduced motion, keyboard access, and contrast-sensitive states.
