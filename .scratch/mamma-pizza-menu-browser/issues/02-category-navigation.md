# 02: Category Navigation

**What to build:** Let Readers move between the six menu Categories through circular emoji Story Circles with English labels. Selecting a Category opens its first Story, resets its progression state, and keeps the Menu Browser focused on browsing.

**Blocked by:** 01: Menu Browser foundation.

**Status:** ready-for-agent

- [ ] Six emoji Story Circles appear above the Story Frame.
- [ ] Each Story Circle has an English Category label.
- [ ] Pizza, Antipasti, Pasta, Insalate, Dolci, and Drinks are selectable.
- [ ] Active Story Circle has a clear visual state and accessible state.
- [ ] Pointer selection changes Category.
- [ ] Keyboard selection changes Category.
- [ ] Category changes open the selected Category's first Story.
- [ ] Category changes reset Story progression and resume automatic playback readiness.
- [ ] User-facing tests verify all six Story Circles, active state, pointer access, keyboard access, and Category reset.
